# P1 凸函数离散化程序使用说明

本项目用连续的 P1 分片仿射函数表示 $u=-\Theta_P$，并在三角剖分上加入凸性约束，求解

$$
\Psi_h(u_h)=\frac12 u_h^{\mathsf T}M u_h+b^{\mathsf T}u_h.
$$

求解器使用 OSQP。每个细化层级都会保存网格、节点值、梯度和诊断信息。

## 算法概览

程序把输入多边形 $P$ 上的未知函数表示为连续的 P1 分片仿射函数。也就是说，每个网格节点 $i$ 只有一个未知数 $u_i$，在三角形内部通过重心坐标线性插值：

$$
u_h(x)=\sum_{i\in T}u_i\,\varphi_i(x),
$$

其中 $\varphi_i$ 是 P1 节点基函数。因为相邻三角形共用同一个节点值，函数在公共边上自动连续；每个三角形上的梯度是常向量。

对所有三角形积分得到质量矩阵 $M$。一个三角形 $T$ 的局部矩阵为

$$
M_T=\frac{|T|}{12}
\begin{pmatrix}
2&1&1\\
1&2&1\\
1&1&2
\end{pmatrix}.
$$

边界积分被组装到线性项 $b$ 中，于是离散泛函变成

$$
\Psi_h(u)=\frac12u^{\mathsf T}Mu+b^{\mathsf T}u.
$$

对每条内部边，程序取两侧三角形的第三个顶点。将一侧三角形的仿射函数延拓到另一侧第三个顶点，要求延拓值不超过该顶点的实际节点值。这给出一个线性不等式；对所有内部边收集后得到 $Au\geq 0$。这组约束正好保证连续 P1 函数在整个三角剖分上凸。因此每一级实际求解的是严格凸二次规划：

$$
\min_u\ \frac12u^{\mathsf T}Mu+b^{\mathsf T}u
\quad\text{subject to}\quad Au\geq0.
$$

OSQP 求出节点向量 $u$ 后，程序再计算 $\Theta=-u$、每个三角形的梯度、梯度跳跃、最佳全局仿射拟合残差和其他诊断量。

## 网格与 level

`level` 表示从初始扇形剖分开始进行标准 red refinement 的次数，不是只计算某一个孤立的网格：

- `level=0`：从第一个多边形顶点出发作扇形剖分。若多边形有 $n$ 个顶点，则有 $n-2$ 个三角形。
- 从 level $k$ 到 $k+1$：每个三角形的三条边各取中点，连接三个中点，分成 4 个子三角形。
- 因此每一级网格都包含上一级网格，有限元空间也是嵌套的。

设输入多边形有 $n$ 个顶点，则 level $k$ 的规模可以直接估算为

$$
T_k=(n-2)4^k,
\qquad B_k=n2^k,
$$

$$
V_k=1+\frac{T_k+B_k}{2},
\qquad E_k^{\mathrm{int}}=\frac{3T_k-B_k}{2},
$$

其中 $T_k$ 是三角形数，$B_k$ 是边界子边数，$V_k$ 是节点数，$E_k^{\mathrm{int}}$ 是内部边数。未知数个数是 $V_k$，凸性约束条数是 $E_k^{\mathrm{int}}$。所以每次 level 加 1，三角形数和约束数大约变为原来的 4 倍，节点数也接近 4 倍；计算和内存会快速增加。

以 5 边形 `d5_a70` 为例，实际规模如下：

| level | 节点数 $V_k$ | 三角形数 $T_k$ | 内部边数 $E_k^{\mathrm{int}}$ |
|---:|---:|---:|---:|
| 0 | 5 | 3 | 2 |
| 1 | 12 | 12 | 13 |
| 2 | 35 | 48 | 62 |
| 3 | 117 | 192 | 268 |
| 4 | 425 | 768 | 1,112 |
| 5 | 1,617 | 3,072 | 4,528 |
| 6 | 6,305 | 12,288 | 18,272 |
| 7 | 24,897 | 49,152 | 73,408 |

因此 `--max-level 7` 会依次求解 8 个问题，最后一个问题已经有约 2.5 万个未知数和 7.3 万条凸性约束。`--max-level 8` 会继续生成约 9.9 万个节点、19.7 万个三角形和 29.4 万条内部边，通常需要明显更多时间和内存。

## 细化时如何继续计算

程序在同一次运行中按 `level=0,1,\ldots,\text{max-level}` 顺序计算。进入下一级时：

1. 保留旧节点的函数值；
2. 每个新边中点取其两个端点值的平均值，这就是旧 P1 函数在新网格上的精确 prolongation；
3. 用这个 prolongation 作为 OSQP 的 warm start；
4. 计算新解与 prolongation 的 $L^2(P)$ 差异，并把新解保存为下一级的历史解。

该 prolongation 在新网格中仍满足凸性约束，因此不仅用于加速，也提供了一个可行的初始点。若程序被中断，已经写入磁盘的各级 `.npz` 和 `.json` 可以保留用于查看；但应从最后一个 `status=solved` 的 level 继续，而不要把 `status=interrupted` 且解向量不完整的文件当作初值。

## 文件

- `convex_p1.py`：主程序和公开接口。
- `plot_minimizer.py`：把计算得到的 `.npz` 解转换为可旋转的 3D HTML 图。
- `unstable_polytope/`：输入的多边形顶点文件。
- `requirements.txt`：Python 依赖。
- `test_convex_p1.py`：几何、积分、凸性、细化和求解测试。

每个输入文件中的非注释行是顶点坐标；注释行中的 `key=value` 会保存到 `PolygonSample.metadata`。顶点必须按逆时针排列，且多边形必须严格凸、无零长度边。

## 运行计算

主程序默认读取 `unstable_polytope/`，计算 level $0,\ldots,8$，并把结果写入 `results/`：

```bash
python3 convex_p1.py
```

指定输出目录和最高 level。例如计算样例 `d5_a74` 的 level $0,\ldots,4$：

```bash
python3 convex_p1.py \
  --input-dir unstable_polytope \
  --output-dir results_d5_a74_l4 \
  --max-level 4 \
  --sample d5_a74
```

注意：`--max-level 4` 按照嵌套空间顺序计算 level $0,1,2,3,4$，不是只计算 level 4。这样可以使用上一级解的 P1 prolongation 作为 warm start，并计算与上一级解的 $L^2(P)$ 差异。

可以用多个 `--sample` 指定多个样例：

```bash
python3 convex_p1.py \
  --output-dir results_two_samples \
  --max-level 2 \
  --sample d5_a70 \
  --sample d6_a140
```

可用样例名可以查看：

```bash
find unstable_polytope -maxdepth 1 -type f -name 'd*' -exec basename {} \;
```

先完成计算，再用对应 level 的压缩网格文件生成 HTML。例如上面的 `d5_a74` level 4：

## 输出文件

对每个样例和 level，程序生成：

- `<sample>_level<k>.npz`：`nodes`、`triangles`、`values_u`、`values_theta`、`triangle_gradients`。
- `<sample>_level<k>.json`：目标值、OSQP 状态、迭代数、残差、约束违约、网格统计、仿射拟合残差、梯度跳跃和细化差异。
- `summary.csv`：所有样例和 level 的汇总表。

其中 `values_u` 是最小解的节点值，`values_theta=-values_u`。梯度跳跃诊断采用相对阈值

$$
\|[\nabla u_h]\|>\max\left(10^{-9},10^{-6}\max_T\|\nabla u_T\|\right).
$$

数值梯度跳跃和最佳全局仿射拟合残差可以用来观察解是否呈现非仿射结构，但有限 level 实验本身不是对极限函数非仿射性的严格证明。

## 从 crease 位置精确求解割线

`exact_crease_decompose.py` 是独立的精确割线分解程序。它先读取
`convex_p1.py` 生成的 `.npz`，把相邻三角形梯度跳跃较大的内部边连接成 crease，
用这些边拟合割线并确定割线端点所在的原多边形边。这个步骤只用于确定边对和选择
解的分支。

确定边对后，程序用符号有理算术构造两片多边形的面积矩和边界矩，得到

```text
ell_left(U) - ell_right(U) = 0
ell_left(V) - ell_right(V) = 0
```

清除矩阵行列式分母后形成两个关于边参数 `s,t` 的整数多项式，再用结式消元。
程序对 resultant 的根使用 Sturm 型精确区间算法，输出 `[0,1]` 内的有理隔离区间；
因此即使端点不是有理数，也能给出它满足的精确多项式和根的隔离区间。有限元
crease 只用于确定候选边对和筛选相关分支，不参与最终端点数值的近似求解。

例如对 `d6_a887` 的 level 7 结果运行：

```bash
python3 -m pip install -r requirements.txt
python3 exact_crease_decompose.py \
  --polygon unstable_polytope/d6_a887 \
  --npz results_d6_a887_l7/d6_a887_level7.npz
```

测试例 `d5_a382` 的 level 7 结果可将两个路径替换为
`unstable_polytope/d5_a382` 和 `results_d5_a382_l7/d5_a382_level7.npz`。

程序会同时写出三个类型的结果：JSON 机器可读结果、同目录下的 Markdown 摘要，以及
每个候选边对对应的 `.txt` 详细方程文件。日常查看优先打开 `.md`；高次二维方程、
resultant 和完整根列表通过摘要中的链接打开，不会把数十万字符直接挤在摘要页面中。
输出会列出 crease 的边数、拟合得到的近似端点、候选边对、二维多项式方程的次数、
两个 resultant 的次数以及根的隔离区间。`exact_solutions` 只列出已经确认的有理根；代数根
列在 `s_root_isolating_intervals` 和 `t_root_isolating_intervals` 中。程序同时用一阶
子结式给出 `paired_root_boxes`，把同一个二维代数根的 `s` 区间和 `t` 区间配对；
经过有限元近似分支筛选的结果列在 `selected_algebraic_root_boxes`，其中还给出两个
割点的十进制近似和坐标隔离矩形；摘要中的 `s approx.`、`t approx.` 是有理隔离区间
中点的浮点显示，不替代精确区间。若要查看全部
被标记的有限元边，追加 `--show-crease-edges`；用 `--output result.json` 可以同时
保存 JSON 结果；省略时还会自动生成同名 `.md` 报告和候选系统详细 `.txt` 文件。分支筛选窗口默认为每个边参数的 `0.5`，可用
`--branch-window` 调整；它只选择候选根，不参与多项式求解。省略 `--output` 时，
JSON 自动写入 `.npz` 所在目录，文件名会去掉 level 后缀，例如
`d5_a382_level7.npz` 对应 `d5_a382_exact.json`。若
`common_factor_requires_review` 为真，说明两个吻合方程还有非分母型公共分支，
程序会保留该因子并提示需要单独分析。

### 代数顶点不稳定性扫描

`algebraic_unstable_scan.py` 对每个代数端点子多边形用隔离盒中点进行数值筛查，
测试简单凸函数 `g=max(a*x+b*y+c,0)` 的相对 Donaldson--Futaki 不变量

```text
M_l(g) = integral(boundary P, g d sigma) - integral(P, g ell_P dx).
```

继承的原始边使用格点测度 `gcd(|dx|,|dy|)`，新增割线边固定为零测度。程序计算
面积矩、带测度边界矩和 `ell_P`，并扫描方向与偏移网格；`--scan-refine` 可在最小
网格点附近加密。扫描不是严格半稳定性证明：`unstable` 表示发现可信负 witness，
`no_counterexample_found` 表示扫描范围内未发现负值，`inconclusive` 表示隔离盒过宽
或数值误差无法控制。默认情况下 `inconclusive` 候选排除，使用
`--keep-inconclusive` 可保留并明确标记。

每个候选的凹性检验、左右子片独立扫描和筛选原因写入 JSON 的
`candidate_screening`，同时在 Markdown 报告中列出。相关参数为
`--scan-theta-steps`、`--scan-t-steps`、`--scan-precision`、`--scan-refine` 和
`--keep-inconclusive`；结果与输入 `.npz` 放在同一目录。
